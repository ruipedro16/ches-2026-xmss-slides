\begin{frame}{\xmss: Overview}
  \begin{itemize}
      \setlength{\itemsep}{4mm}
    \item XMSS~\cite{DBLP:conf/pqcrypto/BuchmannDH11} is a stateful
      hash-based signature scheme.
    \item Security relies on the security of the underlying hash function.
    \item XMSS combines a one-time signature scheme (\wots) with a Merkle tree.
      \vspace{2mm}
      \begin{itemize}
          \setlength{\itemsep}{1mm}
        \item The root of the Merkle tree is the public key of the
          XMSS instance.
        \item Each leaf corresponds to a (compressed) \wots public key.
        \item A Merkle tree of height $h$ has $2^h$ leaves, and thus
          allows signing $2^h$ messages.
      \end{itemize}
  \end{itemize}
\end{frame}

\begin{frame}{\xmss: Operations}
  \begin{itemize}
    \setlength{\itemsep}{4mm}
    \item \textbf{Key generation:} Generate one-time signing keys and build
      a Merkle tree from their public keys. The tree root forms part of
      the XMSS public key.
    \item \textbf{Signing:} Sign the message digest with the next unused
      one-time key and include its authentication path in the signature.
      Update the signing state to prevent key reuse.
    \item \textbf{Verification:} Recover the one-time public key from the
      signature and use the authentication path to reconstruct the tree
      root. Accept if it matches the root in the XMSS public key.
    \item \textbf{TreeHash:} An algorithm used to compute the root of a
      subtree by repeatedly hashing pairs of nodes, starting from its leaves.
  \end{itemize}
\end{frame}
